# esp_ble_wifi_provisioning (Flutter package)

A publishable Flutter/Dart package that hides all BLE, crypto, and protocol
detail behind a small, well-documented API (`EspBleProvisioning` /
`EspProvisioningSession`). Mirrors the firmware handshake and framing
byte-for-byte so it interoperates with the `wifi_ble_prov` component.

> **Not yet implemented.** Scaffolding only — internal layers and the public
> API come in a later phase.
