# blifi (Flutter package)

A publishable Flutter/Dart package (`blifi` on pub.dev) that hides all BLE,
crypto, and protocol detail behind a small, well-documented API. Mirrors the
firmware handshake and framing byte-for-byte so it interoperates with the
`blifi` ESP-IDF component.

> **Not yet implemented.** Scaffolding only — internal layers and the public
> API come in a later phase.
